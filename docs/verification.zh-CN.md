# 验证范围

[English](verification.md)

构建引擎并生成合成示例后，运行 `python -m pytest -q`。测试实际执行 Pascal 程序，
不是用 Python 近似公式代替原生求解器。

- 矩形箱体解析对照：体积、浮心、水线面积、横向和纵向稳心半径。
- 平移、对称和缩放：检查体积、水线面积、坐标基准与尺度变化规律。
- 原生网格、图层和单位保存后重读；`.fbm` 无修改写回按字节核对。
- `fv335`、`fv462` 的 `.fbm` 与 `.ftm` 互转。
- 几何容积与修正容积区分；公制及英制物理单位换算。
- 合成船型的 Lackenby 变换、上游收敛阈值及独立三维静水力残差。
- 无浸水、破损模型、不可达目标、超时与取消，不留下假成功输出。
- 中文及俄文路径、显式区间展开与中间进度通知。
- 真实 MCP 客户端初始化、发现 13 个工具并完成整个调用链。
- 独立 Windows 程序运行时，PATH 仅保留系统目录，不能依赖开发用 Python、Pascal 或 FreeShip。
- 独立 DXF 解析、视图和站位坐标；Excel 数值和图表引用范围。
- 从公开文件清单的干净副本重新构建并运行原生解析测试。

矩形箱体体积使用相对容差 `2e-6`，水线面积及稳心半径使用相对容差 `1e-4`。
这是数值测试的误差界限，不是软件替用户选取的船型设计裕量。

实际运行记录见 `docs/test-results.json`。GitHub CI 配置文件不能视为 CI 已经通过；
本机独立包测试也不等于已经在另一台全新 Windows 虚拟机上测试。

船型变换的验收需要调用者明确提供目标排水量和浮心位置。
程序不会推测经验目标，也不会把母型值默认为设计要求。
