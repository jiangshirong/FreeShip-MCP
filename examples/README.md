# Original synthetic examples

`box.fbm`: symmetric half-box, L=20 m, B=6 m, height=8 m, draft=4 m, density=1.025 t/m³,
appendage coefficient=1.0. Analytic immersed volume=480 m³ and displacement=492 t.

`synthetic-hull.fbm`: original smooth synthetic hull generated by `scripts/create_examples.py`;
40×8 m project dimensions, draft 3 m, very-high native subdivision precision. It is a
software regression fixture, not a design recommendation or a real ship.

Both use fv462 and contain no third-party model data or personal information.
Regenerate using `python scripts/create_examples.py --output-dir examples`.
